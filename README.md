# Linear Regression Projects Using Python

## About the Project

This repository contains beginner-friendly Machine Learning examples using Linear Regression and Python.

## Projects Included

### 1. Simple Linear Regression

* **Goal:** Predict student marks based on study hours.
* **Algorithm:** Simple Linear Regression
* **Libraries:** NumPy, Scikit-learn

### 2. Multiple Linear Regression

* **Goal:** Predict house prices based on area, number of bedrooms, and house age.
* **Algorithm:** Multiple Linear Regression
* **Libraries:** NumPy, Pandas, Scikit-learn

## Technologies Used

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Scikit-learn

## How to Run

1. Clone or download this repository.

2. Install the required libraries:

   `pip install numpy pandas scikit-learn jupyter`

3. Open the notebook using Jupyter Notebook.

4. Run the cells to see the predictions.

## Learning Outcomes

* Understanding simple and multiple linear regression
* Training a machine learning model
* Making predictions using Scikit-learn
